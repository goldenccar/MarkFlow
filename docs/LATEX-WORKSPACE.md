# Fomula：公式与 LaTeX 文档

[使用指南](USAGE.md) · [产品需求](PRD.md) · [实施清单](../OopsMD-TODO.md#paper-workspace-todo)

入口：顶部标签栏 **＋ → Fomula**，或文件菜单 **Fomula · 公式与 LaTeX**。同一入口中选择 **公式片段 / LaTeX 文档**：片段即时显示数学排版，完整文档保存多文件项目并显示实际编译的分页 PDF。已有文档类型、草稿与标签记录保持兼容。

Markdown、公式片段和完整文档使用唯一的应用栏与项目侧栏。应用栏固定按 **打开文件 → 主题 → 版本历史 → 保存** 排列；差异命令放在第二栏，LaTeX 的 **编译环境** 入口也在这里，主文件、引擎和停笔后编译集中在 **编译选项**。通用设置与 Git 入口保留在系统侧栏底部。源码字体、字号和行距沿用通用设置，成品字体与纸张仍由页面设置决定。

论文新建、打开、ZIP 导入、Mark 生成及独立副本统一加入系统项目列表，复用同一文件树/文件夹树、归档、拖动、右键和 Git 面板。论文编辑区只负责源码、编译、PDF 与页面设置；没有另一套私有项目栏或应用首栏。

## 页面配置与新建

完整文档工具栏提供 **页面设置**。左侧设置纸张、方向、四边页边距、单双栏、字号、行距、首行缩进、页眉页脚、页码和 PNG/JPEG 标志；右侧保留 PDF。配置面板的小纸张是比例示意，最终分页以编译后的 PDF 为准。设置应用到主文件，支持一次撤销；保存仍由用户执行。启用 **停笔后编译** 后，修改自动更新预览。

页面设置在源码区域内展开和收起，保留右侧 PDF 节点、宽度与滚动位置；窄窗口使用源码/PDF 切换。按 Esc 可关闭设置。开合提供 180 毫秒过渡，系统启用减少动态效果时直接切换。

页眉页脚支持普通文字与 `{title}`、`{author}`、`{page}`、`{pages}` 占位符。图片保持比例并限制在对应栏宽内。设置以受控区保存在 TeX 中，无需手写 JSON。外来模板若已有复杂自定义页面规则，表单会说明冲突并保留源码。Mark 生成的只读项目需要先 **另存为独立 LaTeX** 才能改变页面。

新建同名项目使用“名称 (2)”等空闲名称，不覆盖旧文件夹；真正关闭 Fomula 文档标签会释放会话。完整 `.tex` 及所属项目的章节、文献和样式文本从系统文件树进入文档工作区；打开 `sections/chapter.tex` 保留已授权项目根，不把 `sections` 另当项目。独立公式片段保留即时数学预览。外部项目的本地编译仍需信任确认。

源码支持单独输入 `/` 或 `\` 呼出提示，输入字母筛选，Tab 插入、方向键选择、Esc 关闭。没有补全菜单时 Tab 缩进两空格，Shift+Tab 反向。匹配程度优先，其次是本机接受次数和最近接受时间；仅存命令统计，不保存正文。

## 开始写作

1. 选择中文论文、英文单栏或英文双栏，填写项目名称、标题和作者，再选择存放位置。模板会创建主文件、独立章节和参考文献文件。
2. 也可从左侧项目加号打开已有文件夹，或在 LaTeX 首页导入源文件 ZIP。多个候选主文件时，展开第二栏 **编译选项**，确认主文件及 XeLaTeX、pdfLaTeX 或 LuaLaTeX 引擎。
3. 在系统文件树选择源文件编辑；项目文件旁的 **新建文件** 可输入 `sections/new.tex` 等相对路径。点击 **编译** 或按 **Ctrl+Enter**，右侧显示 PDF；可启用“停笔后编译”。正文、章节和文献中已打开的未保存修改一起进入编译快照。
4. 点击应用栏 **保存** 或按 **Ctrl+S** 写入修改过的源文件，版本记录使用共享 Git 面板。编译不自动保存，不清除未保存状态。设备草稿在切换和关闭时保留，从项目列表重新打开文件即可恢复。
5. 点击 **导出** 交付 PDF 或可复现源文件 ZIP。导出的是上一次成功编译的快照；当前内容已变化时会提示版本差异。选择源项目之外的位置，防止覆盖来源。

## 阅读、定位与常用操作

- 源码和 PDF 独立滚动。PDF 提供连续跨页、缩放、页码跳转和可见区域绘制。
- **定位 PDF** 将当前源码位置映射到成品；按住 **Ctrl** 点击 PDF 页面可定位回源文件。只有与当前内容一致的预览才能使用定位，旧 PDF 不猜测新源码位置。
- 工具栏可插入章节、公式、图片、表格和项目 `.bib` 中的引用键。自定义宏仍直接在源码编辑，不会被自动转成 Mark。
- 编译错误显示文件和行，可展开原始日志。失败或取消保留上一份有效 PDF；错误源码仍可编辑和撤销。
- 保存遇到外部修改会拒绝覆盖，提供磁盘内容核对，保留设备草稿；明确核对后才能继续保存。
- 系统树改名/移动会迁移全部相关 LaTeX 草稿，包括本次未打开的文件。目标恢复记录冲突时先拒绝操作；磁盘已移动而草稿迁移失败时保留旧记录并提示。存在未保存恢复草稿时阻止删除。项目重新定位会复制草稿及主文件/引擎配置到新位置的设备记录，保留旧备份。

## 本轮支持范围

已在 Windows 开发构建验证中文、英文单栏/双栏、多文件章节、公式、表格、交叉引用、BibTeX，以及子目录主文件＋Biber。导出的源包可重新导入编译，保留主文件与引擎记录。图片通过项目素材导入和标准 `graphicx` 使用；各出版社自定义类和宏包仍需单独验证。

可编辑文本采用 UTF-8，支持 `.tex/.bib/.cls/.sty/.bst` 等论文文件；保存保留原 BOM 与换行方式。项目不超过 3,000 个文件、总资源 128 MiB，单文件 32 MiB，可编辑文本 4 MiB。ZIP 导入和快照排除构建缓存、隐藏目录与可执行文件，拒绝越界路径和符号链接。

外来项目需要明确确认信任才能编译。当前禁止项目 `.latexmkrc`、shell escape，限制可调用工具并使用单独构建目录，但**尚无操作系统级隔离**；这些措施不保证恶意 TeX 不能访问本机文件。只编译可信来源。

2026-10-31 已补应用内离线环境安装、进度、取消/重试与回退；Windows 冻结环境包约 341 MiB（357 MB），包含实际使用的宏包、字体和文献工具。详见[环境分发说明](LATEX-ENVIRONMENT.md)。

论文首页的“资料来源”现在可选**当前 Markdown**或**本地 Mark / Markdown**。选择中文、英文单栏或双栏模板，填写标题、作者和可选摘要即可创建。参考文献可展开填写标识、标题、作者、年份；正文用 `[@ref1]` 引用。右侧 PDF 由同一条真实 TeX 编译链生成。

生成稿保留输入快照、Mark ID、修订和源码位置。源码默认只读；在对应源码位置点击“定位原文 Mark”可返回尚未变化的当前 Markdown。编译诊断可定位 Mark；PDF 双击经 SyncTeX 定位到源码后也可返回 Mark。需要直接编辑生成稿时点击“另存为独立 LaTeX”，原 Mark 与生成快照不改写。系统文件树同样阻止修改、添加、移动或删除生成来源，逻辑归档可保留；外部修改或删除生成稿文件会使校验失败，避免继续显示错误的来源位置。

支持范围：标题/段落/列表/PNG 与 JPEG/表格、受限数学语法、文献、交叉引用。普通 Markdown 没有持久身份登记时会明确提示临时 ID；不承诺跨编辑稳定。字体族遵循论文模板并给出诊断；双栏长表、五六级标题精确层级、任意自定义 TeX 宏不保证保真。原生 LaTeX 工作区继续用于复杂论文工程。

尚未完成：实际 macOS 验收、干净操作系统与真实断网验收、任意缺失宏包的自动修复、完整出版社模板兼容、Overleaf 性能对照，以及 Note 的模板配置/浏览器分页编辑器。Mac 操作见[实机验收说明](MACOS-ACCEPTANCE.md)，Windows 结果不能代替 Mac 结果。

## 本地开发

首次在 Windows 开发机准备论文运行环境：

```powershell
npm ci
npm run prepare:tex
npm run dev
```

本次调试机已经准备完成，后续直接运行 `npm run dev`。开发环境位于 `vendor/tex/TinyTeX`。构建者通过 `npm run package:tex` 将已准备环境冻结，再用 `npm run pack:paper` / `npm run dist:paper` 生成带环境资源的 Windows 应用。终端用户在应用内安装，既不调用 tlmgr 联网补包，也不改变系统 PATH。轻量应用可通过“导入离线环境包”安装同版本资源，校验不通过不会激活。

验证入口：

```powershell
npm run test:paper
npm run test:paper:native
npm run build
npm run test:paper:desktop
```

真实编译需要先准备运行环境。桌面检查创建独立测试项目和 profile，不操作日常论文。Mark 跨格式原生测试使用 `npm run test:paper:mark`；真实 Mac 验收使用 `npm run test:paper:mac -- --app /absolute/path/MarkFlow.app`。实际验证记录见[本轮交付记录](PAPER-DELIVERY.md)。
